# DevBox

A Dev Environment in a box, preloaded with all your scratch pad tooling. No setup required just open it and start building.

DevBox comes ready to use with:

- **Mise** - a curated set of runtimes and developer tools installed and managed with mise, so a scratch pad of tools to hit the ground running. Also you can have your own project level `mise.toml` to define your own tools.

- **Pitchfork** - a built in background process handler to run servers and daemon inside the dev box without systemd in user space.
  
- **Podman** - a built in container runner to run containers right inside the box no need docker compose.

Open it, and you're ready to go.
